1. Reglas de Evaluación en Windows Server (NTFS + SMB)

Cuando un usuario accede a un recurso en Windows Server, el subsistema de seguridad (SRM) evalúa los permisos siguiendo tres leyes estrictas:

  • Unión de Grupos: El usuario acumula los permisos concedidos a su cuenta individual más todos los grupos a los que pertenece (mgarcia ∪ Ventas_Group ∪ Users).
  • Precedencia de ACEs: Las entradas explícitas tienen prioridad sobre las heredadas, y Denegar prevalece sobre Permitir en el mismo nivel: 1º Deny Explícito > 2º Allow Explícito > 3º Deny Heredado > 4º Allow Heredado.
  • Intersección Share SMB ∩ NTFS: Al acceder por red (\\WIN-SRV01\Carpeta), el permiso efectivo final es el más restrictivo entre el permiso de la pestaña Compartir y la pestaña Seguridad (NTFS). 
# Ver ACL en consola de Windows:
icacls "C:\Empresa\RRHH\Nominas_2026.xlsx"

# Deshabilitar herencia convirtiendo en explícitos y dar Modificar a RRHH:
icacls "C:\Empresa\RRHH\Nominas_2026.xlsx" /inheritance:d /grant "EMPRESA\RRHH_Group:(M)" /remove:g "WIN-SRV01\Users"

2. Permisos Tradicionales UGO y Bits Especiales en Linux

Cada inodo almacena 12 bits de modo divididos en 4 octetos: Especiales (4/2/1), Propietario u (4/2/1), Grupo g (4/2/1) y Otros o (4/2/1).

  • SUID (Octal 4000 · chmod u+s): En ejecutables binarios, el proceso se ejecuta con el EUID del propietario del fichero (p. ej. root). Se muestra como rws en el propietario.
  • SGID (Octal 2000 · chmod g+s): En directorios (p. ej. /var/www/html), hace que todos los archivos y subdirectorios nuevos creados dentro hereden automáticamente el grupo del directorio contenedor.
  • Sticky Bit (Octal 1000 · chmod +t): En directorios compartidos (como /tmp o /var/www/compartido), impide que un usuario borre o renombre archivos que pertenezcan a otros usuarios. Se muestra como rwt al final. 
# Directorio web colaborativo con SGID activo:
sudo chown -R :www-data /var/www/html
sudo chmod 2775 /var/www/html

# Directorio compartido protegido con Sticky Bit:
sudo chmod 1777 /var/www/compartido

3. Listas de Control de Acceso POSIX (getfacl / setfacl)

Cuando UGO no basta para dar acceso a usuarios o grupos concretos, se emplean ACLs extendidas (indicadas con un signo + al final de ls -l, ej. drwxrwsr-x+).

  • La Máscara ACL (mask::): Define el permiso máximo efectivo para todos los usuarios nombrados (user:nombre:), grupos nombrados (group:nombre:) y el grupo propietario (group::).
  • Atención con chmod sobre archivos con ACL: con ACL extendida, los bits de grupo que ves en ls -l son la máscara. Ejecutar chmod después de setfacl modifica mask:: (no group::), pudiendo dejar entradas con #effective:r-x aunque tengan rwx asignado. 
# Inspeccionar ACL y permisos efectivos:
getfacl /var/www/html

# Dar rwx al usuario jdoe y recalcular la máscara a rwx:
sudo setfacl -m u:jdoe:rwx /var/www/html
sudo setfacl -m m::rwx /var/www/html

# Dar solo lectura a un auditor externo sobre un fichero sensible:
sudo setfacl -m u:auditor:r-- /var/www/config.php

4. Resumen de los 10 Tickets Reales del Help Desk

Cada ticket simula una incidencia real de administración de sistemas que puedes verificar en tiempo real:

  • INC-4081 (Win): Conflicto entre Share SMB en Leer y NTFS en Presupuesto_Ventas.xlsx.
  • INC-4085 (Win): Denegación explícita en Users bloqueando a un miembro de Finanzas_Group.
  • INC-4090 (Win): Ruptura de herencia NTFS y blindaje de Nominas_2026.xlsx para RRHH_Group.
  • INC-4094 (Win): Permisos de Lectura y ejecución para DevOps_Group en script crítico de producción.
  • INC-4099 (Win): Publicación SMB y acceso colaborativo interdepartamental en Proyectos_2026.
  • INC-5102 (Linux): Permisos de Apache (www-data) y herencia de grupo con bit SGID (2775).
  • INC-5108 (Linux): Diagnóstico de bloqueo por máscara POSIX ACL (mask::r-x vs u:jdoe:rwx).
  • INC-5115 (Linux): Protección contra borrado cruzado con Sticky Bit (1777) y blindaje de deploy.sh.
  • INC-5120 (Linux): Elevación controlada con bit SUID (4755) en binario bin_healthcheck.
  • INC-5125 (Linux): Hardening 0640 de config.php + acceso puntual a auditor con setfacl.
